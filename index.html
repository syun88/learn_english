Grammar map

必要な文法を、使う形で確認する

説明を読むだけではなく、「Form（形）→ Meaning（意味）→ Example（例）→ Output（自分で作る）」の順で見ます。

不是只看說明，而是依「形式 → 意義 → 例句 → 自己輸出」來理解。

01

5文型

SV / SVC / SVO / SVOO / SVOC

ポイント: 英語は語順が役割を決める。

重點: 英文靠語序決定句子角色。

I work. SV

She is kind. SVC

I study English. SVO

He gave me a book. SVOO

They made me happy. SVOC

Output → “I ___.” “I ___ something.” の2文を作る。

02

be / do / have

be = state do = action support have = possession/perfect

ポイント: be動詞文ではdoを使わない。一般動詞の疑問・否定にはdo系を使う。

重點: be 動詞句不用 do；一般動詞的否定與疑問要用 do/does/did。

She is busy.

She does not work today.

Does she work here?

She has finished the task.

Output → “I am … / I do not … / I have …” を1文ずつ。

03

動詞5変化

base → 3rd person → past → p.p. → -ing

go→goes→went→gone→going

使い分け: 原形は助動詞後、過去分詞は完了/受動、ingは進行/動名詞。

用法: 原形接助動詞；過去分詞用於完成/被動；ing 用於進行/動名詞。

Output → go / make / study の5変化を声に出す。

04

肯定・否定・疑問

be: He is busy. → He isn't busy. → Is he busy?

do: He works. → He doesn't work. → Does he work?

注意: Does he studies? ではなく Does he study?

注意: does 已經帶有第三人稱資訊，所以主要動詞回原形。

Output → “She likes coffee.” を否定・疑問へ変換。

05

12時制

TimeSimpleProgressivePerfectPerfect Progressive
PresentI study.I am studying.I have studied.I have been studying.
PastI studied.I was studying.I had studied.I had been studying.
FutureI will study.I will be studying.I will have studied.I will have been studying.

覚え方: 時間（現在/過去/未来）と見え方（単純/進行/完了/完了進行）を分けて考える。

記法: 分開理解「時間」與「動作狀態」，不要把 12 個時態當 12 個完全不同的東西背。

Output → “study” を現在・過去・現在進行・現在完了の4つで言う。

06

助動詞

modal + base verb

  • can — 能力 / 可能
  • could — 過去能力 / 丁寧
  • may — 許可 / 可能性
  • must — 義務 / 強い推量
  • should — 助言 / 当然
  • would — 丁寧 / 仮定

Output → “I can … / I should … / I would …”

07

to / -ing / participle

I want to learn.

I enjoy learning.

a broken robot

the person standing there

ポイント: to不定詞は「これから/目的」、動名詞は「行為そのもの」と捉えると整理しやすい。

重點: to 常帶「接下來/目的」感，動名詞則把行為本身當名詞。

Output → want to / enjoy -ing で自分の文を作る。

08

節・関係詞

I think that it works.

The book that I bought is useful.

I will call you when I arrive.

ポイント: 文の中に「小さい文」を入れて情報を増やす。

重點: 把一個「小句子」放進主句裡增加資訊。

Output → “I think that …” で1文。

09

受動・比較・仮定

The system was built by students.

This method is faster than that one.

If I had more time, I would study more.

形: passive = be + p.p. / conditional = If + past, would + V

形式: 被動 = be + 過去分詞；假設 = If + 過去式, would + 原形。

Output → “If I had …, I would …” を1文。

Sentence transformation

Practice 2 — 英文を変形する

日本語訳ではなく、元の英文を別の形へ変える練習です。

不是翻譯，而是把原本的英文改成指定形式。

1. He works here. → 否定文否定句

2. She likes coffee. → 疑問文疑問句

3. I go to Tokyo. → yesterday を使って過去形加入 yesterday 改成過去式

4. I study English. → now を使って現在進行形加入 now 改成現在進行式

5. Students built the robot. → 受動態被動態

Writing output

Practice 5 — 自分の英文を作る

「正しい英文を写す」ではなく、自分の情報へ置き換えて書きます。モデル回答は最後に見る。

不要只是抄正確英文，要換成自己的資訊來寫。範例答案最後再看。

Level 1 · 3 sentences

今日の生活

現在形・過去形・未来を1文ずつ使う。

現在式、過去式、未來各寫一句。

Model answer

I usually study at a café. Yesterday, I worked on my project at home. Tomorrow, I will review English grammar.

Level 2 · 4–5 sentences

今取り組んでいること

現在進行形・現在完了・because を使う。

使用現在進行式、現在完成式與 because。

Model answer

I'm currently working on a small software project. I've been developing it for two weeks. I chose this topic because I wanted to learn something practical. It is difficult, but I'm making progress.

Level 3 · 80–100 words

意見を書く

I think / because / however / if を最低1回ずつ使う。

至少各使用一次 I think / because / however / if。

Writing checklist
  • 主語と動詞があるか
  • 時制が途中で不自然に変わっていないか
  • 1文が長すぎないか
  • because / however / if が論理的につながっているか
