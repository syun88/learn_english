S / V / O / C が苦手でも大丈夫

この教材では文法記号を理解の入口にしません。まず「誰が・何が？」「どうする／どういう状態？」「何を・誰に？」「どんな状態・何者？」という意味の役割で英文を読みます。S / V / O / C は、辞書や参考書を読むための補助ラベルとして後から確認します。Grammar Lessonでは「やさしい表記」を標準にしています。

本教材不把 S / V / O / C 當作理解英文的入口。先用「誰／什麼」「做什麼／什麼狀態」「對誰／什麼」「成為什麼狀態」理解句子，文法符號只作為之後閱讀字典與參考書的輔助標籤。

1 Chapter = 1 real class

35は文法ポイントの総数ではなく「教科書の章数」です。各Sub-lessonでRule Recall・例文分析・誤文訂正・自作文を行います。1章の学習時間は最低65分、内容の深い章は90分以上を想定します。速く読み終えることではなく、説明・判断・修正・生成までできることをゴールにします。

35 是教科書章數，不是文法點總數。每個 Sub-lesson 都包含規則回想、例句分析、改錯與自行造句。每章至少65分鐘，內容較深的章節會超過90分鐘。目標不是快速讀完，而是能解釋、判斷、修正與產出。
